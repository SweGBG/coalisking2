# Coal is King

Next.js 15 (App Router, TypeScript). Svenska/engelska, JSON-LD, FAQ, galleri med lightbox.

    npm install
    npm run dev
    npm run build && npm start   # testa på produktionsbygget

Redesign: temat är värme. Mätaren till vänster (termometer, 20 till 800 °C) följer scrollen,
startsidan har en andande kolbädd, rubrikerna "hettar upp" när de visas och menyn är satt som ett
tryckt menykort med punktlinjer och grillränder vid hover. Typsnitt (Big Shoulders Display och
Newsreader) levereras via npm (@fontsource), inga externa typsnittsanrop.

Bilderna i hero, om oss och galleri hämtas fortfarande från Unsplash. Byt mot egna foton innan lansering.
